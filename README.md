# Jeongwoo AI 품질검사 결과서 V13.0 전체본

## V13 추가사항
- 검사신청서 PDF/Excel 불러오기와 기본정보 직접 작성 모두 지원
- 검사자 선택을 드롭다운 방식으로 변경
- 검사자 목록은 가나다순 정렬
- 기본 선택값은 김선웅
- 선택한 검사자명이 Excel 결과서에 자동 반영

## 검사자 목록
김상민, 김선웅, 김희성, 박재암, 송민준, 안병영, 안예지, 유병조, 이승현, 이진원, 이진표

기존 신청서 판독, 검사기준 직접 입력, 사진 잘림 방지, Excel 생성, Outlook 메일 작성 기능을 모두 포함합니다.


## V13 변경사항
- 검사결과서 사진을 360 x 340 px로 축소
- 모든 사진에 좌우 18 px, 상단 8 px 내부 여백 적용
- 오른쪽 사진이 셀 외곽선을 넘어가는 현상 수정
## V13 보완사항
- 결과 파일을 열면 `검사결과서` 갑지가 먼저 표시
- 내부 데이터용 `간편입력` 시트 숨김 처리
- 갑지와 을지 상단 출력 여백을 약 15 mm로 확대하여 바인더 타공 공간 확보
- 갑지와 을지 모두 A4 세로 1페이지 맞춤 출력 유지
